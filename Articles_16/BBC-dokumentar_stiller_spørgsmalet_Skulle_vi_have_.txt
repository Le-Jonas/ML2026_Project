Title: BBC-dokumentar_stiller_spørgsmalet_Skulle_vi_have_
Date: 2022-01-02
Article Type: Set og hørt
Author: Dokumentar fra 2021, 75-året for Nürnbergprocessen, afslører nye indsigter i retssagen mod Hitlers håndlangere.

Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
Bo Tao Michaëlis
Kan der koges mere suppe på det både hæslige og håbefulde ben, som hedder Nürnbergprocessen? Hæslig, fordi der oprulledes grænseoverskridende rædsler, som hedder holocaust, folkemord og organiseret massakre. Håbefuld, fordi denne internationale retssag optimistisk skulle være den sidste af sin slags, den skelsættende advarsel om, at det koster at forbryde sig mod menneskeheden.
Udover utallige dokumentarfilm har Hollywood været der for år tilbage med Burt Lancaster som sofistikeret nazist, Spencer Tracy som retfærdig amerikaner og Marlene Dietrich som femme fatale med hagekors som øreringe.
Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
