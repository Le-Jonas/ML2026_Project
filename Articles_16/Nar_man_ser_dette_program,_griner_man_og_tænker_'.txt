Title: Nar_man_ser_dette_program,_griner_man_og_tænker_'
Date: 2021-10-11
Article Type: Set og hørt
Author: ’Svenska nyheter’ trækker bukserne ned på det svenske samfund på elegant og grov vis, skriver Maja Kiener i denne klumme.

Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
Maja Kiener
Egentlig havde jeg rigeligt med grin, gråd og underholdning i Netflix’ progressive, usentimentale og øjenåbnende ’Sex Education’. Og endnu en satirisk gennemgang af ugens politiske og samfundsbegivenheder var ikke lige det, jeg gad efter en hård uge. Men min mand grinede så højt, så længe og så ofte, at jeg blev nødt til at løfte blikket og se, hvad der foregik.
Og der foregik meget. Komikeren Kristoffer Appelquist var i færd med at riste Sverige i det satiriske tv-program ’Svenska nyheter’ på SVT. Programmet, der med egne ord »forklarer, hvorfor ting er, som de er, hvordan de burde være, og gør grin med det, der er politik, og det, som man ikke ved er politik«.
Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
