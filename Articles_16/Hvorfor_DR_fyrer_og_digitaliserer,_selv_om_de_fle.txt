Title: Hvorfor_DR_fyrer_og_digitaliserer,_selv_om_de_fle
Date: 2022-09-15
Article Type: Medier
Author: Langt størstedelen af danskernes forbrug af DR’s tv-programmer foregår som klassisk flow-tv. Kun en tredjedel bliver set via digitale platforme, som DR nu opruster markant.

Torben Benner
Journalist
Selv om vi streamer mere og mere tv-indhold og er mere og mere digitale, bliver ’Den Store Bagedyst’, ’TV Avisen’, ’Borgen’ og de fleste andre DR-programmer fortsat set på godt gammeldags flow-tv, når de ruller over skærmen. Det viser en opgørelse fra DR Medieforskning baseret på seermålinger fra analysebureauet Nielsen.
66 procent af alt, hvad der bliver set hos DR, bliver set på flow-tv. 34 procent bliver set via streamingtjenesten DRTV eller via digitale DR-tilbud hos distributører som YouSee.
