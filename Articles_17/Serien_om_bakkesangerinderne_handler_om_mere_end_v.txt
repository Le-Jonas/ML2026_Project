Date: 2024-05-07
Article Type: Set og hørt
Author: DR’s serie om syngepigernes lange historie er interessant, fordi den handler om meget mere end vovede viser. Det er en fortælling om kvindefrigørelse og klassesamfund, skriver Henrik Palle i denne klumme.

Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
Henrik Palle
Anmelder af tv, teater og stand-up
Bakkens Hvile på Dyrehavsbakken nord for København er det sidste sangerindeetablissement, der er tilbage. Og angiveligt er stedets økonomi så presset, at dets fortsatte eksistens kan være i fare.
Det ville være ærgerligt, hvis det gik tabt. For godt nok har det lille træhus på Bakken med udsigt til forlystelser og steder, der serverer stegt flæsk med persillesovs og fiskefileter med bjerge af remoulade, ikke noget dragespir. Mindre kan imidlertid gøre det.
Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
