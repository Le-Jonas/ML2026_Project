Title: Det_er_bare_verdens_bedste_program
Date: 2023-04-01
Article Type: Set og hørt
Author: Det handler om cykelløb. Og det er helt forrygende. Snyd derfor ikke Dem selv. Stil ind på tv-programmet ’Radio Tour’, skriver Rasmus Bech i denne klumme.

Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
Rasmus Bech
Journalist
Okay, okay, ’verdens bedste tv-program’ er måske en stramning, men så lad mig geare ned til ’verdens bedste sportsprogram’ – eller måske ’verdens bedste cykelsportsprogram’. Så er vi ved at være der. Og det er dansk, mine damer og herrer, og det produceres af Discovery+, som også tæller Eurosport-kanalerne.
Hør her, når jeg leverer tekst til denne opsats, så handler det hovedsagelig om historiske emner, og gerne om krigen, der aldrig slutter mediemæssigt, nemlig Anden Verdenskrig og Danmarks besættelse fra 1940 til 1945. Men denne gang gælder det min anden store passion: landevejscykling.
Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
