Title: ’Tag_med_Spies_til_Sommerfugledalen’_og_andre_Inst
Date: 2024-03-20
Article Type: Set og hørt
Author: Tænk, hvordan det havde set ud, hvis verdenslitteraturens forfattere var steget ud af elfenbenstårnet for at sælge sig selv på reklamesøjlen Instagram, skriver Bo Tao Michaëlis i denne klumme.

Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
Bo Tao Michaëlis
På Instagram slår det mig heftigt, hvor mange forfattere som hæmningsløst promoverer deres bøger med en ublu markedsføring. Alle kneb gælder for at få spontane læsere som svorne fans.
Derfor tænker jeg på, hvordan det var gået, hvis det sociale medie altid havde været der. Hvis verdenslitteraturens forfattere var steget ud af elfenbenstårnet for at komme hidsigt ind på det markedsførende Instagram.
Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
