Title: Med_hende_som_vært_kan_du_spørge_Gud_om_hvad_som_h
Date: 2024-02-02
Article Type: Set og hørt
Author: Iben Maria Zeuthen er fremragende, når hun på DR tager rundt og taler med fire præster om deres kald, skriver Bo Tao Michaëlis i denne klumme.

Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
Bo Tao Michaëlis
Radiojournalisten Iben Maria Zeuthen har med sin sakralt sagte stemme som stilealterlys sat sin helt egen niche op: Tro i almindelighed og kristendom i særdeleshed. På P1 kan man med hende som vært spørge Jesus om hvad som helst. Okay, siger vi så, og der kan siges både for og imod om udlægningen af Jesu ord som svar i en læserbrevkasse.
Men Zeuthen er dygtig og engageret. Hendes intention er både sympatisk og empatisk. Om menneskets lod i livet, den kranke skæbne og sjælens ubodelig ensomhed. Og så altså Jesu ord.
Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
