Title: Dansk_podcastduo_bobler_over_af_viden_om_rockmusik
Date: 2021-02-05
Article Type: Set og hørt
Author: Siden 2017 har Klaus Lynggaard og Henrik Queitsch udsendt flere end 100 podcasts om de vigtigste musikere, deres historier og mesterværker, deres opture og fald. Og niveauet er kontinuerligt højt.

Siden 2017 har Klaus Lynggaard og Henrik Queitsch udsendt flere end 100 podcasts om de vigtigste musikere, deres historier og mesterværker, deres opture og fald. Og niveauet er kontinuerligt højt.
Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
Sune Højrup Bencke
Journalist
Så meget viden kan ingen holde indenbords. Det må være direkte usundt. For det koger og bobler, det flyder over, og det skal ud.
Jeg skriver selvfølgelig om de to rockkritikere med mere Klaus Lynggaard og Henrik Queitsch, der heldigvis for dem selv og os andre har podcasten ’Rockhistorier’ som det bål, de kan blive ved med at hælde brænde på i form af ufattelige mængder viden om rockmusik og det, der slægter den på.
Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
