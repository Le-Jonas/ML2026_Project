Date: 2020-10-30
Article Type: Set og hørt
Author: DR’s nye dokumentarserie følger tre neglekunstnere i deres stræben efter at få deres udtryk anerkendt som ’rigtig’ kunst, der kan komme på museum og galleri.

Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
Henrik Palle
Anmelder af tv, teater og stand-up
Det var i sin tid kunstneren og humoristen Robert Storm Petersen, der definerede kunst som »det, man ikke kan«. Og argumentet for denne negative vinkel er: »At hvis man kan det, er det jo ingen kunst«.
Så alene derfor er neglekunstdronningerne og seriens hovedpersoner, Anamarija, Nadia og Jenna, diskvalificeret som værende kunstproducenter. De er nemlig ikke alene efne udi deres metier, men suverænt dygtige. Tilmed også opfindsomme, originale, ud af boksen tænkende og endvidere stræbsomme og kloge. De kan noget. Meget, faktisk.
Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
