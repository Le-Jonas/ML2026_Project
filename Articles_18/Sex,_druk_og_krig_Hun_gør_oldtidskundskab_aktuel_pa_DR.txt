Title: Sex,_druk_og_krig_Hun_gør_oldtidskundskab_aktuel_pa_DR
Date: 2025-05-11
Article Type: Set og hørt
Author: Oldtidskundskab kan sagtens være vedkommende og aktuelt. Bare se Bettany Hughes’ programmer om de gamle guder på DR, skriver Bo Tao Michaëlis i denne klumme.

Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
Bo Tao Michaëlis
Den engelske klassiske historiker Bettany Hughes har skabt en række fremragende fjernsynsprogrammer om antikken og dens arv.
De kan ses på DR, hvis kultur ellers kan ligge på et meget lille sted, og handler om alt fra demokratiet i Athen, hvor Hughes også trak på vores verdensberømte ekspert i så henseende, Mogens Herman Hansen, til egyptiske mumier og Pompeis skatte.
Set og hørt er Politikens daglige klumme om tv, streaming, radio og podcast. Den skrives på skift af avisens skribenter og er udelukkende udtryk for skribentens egen holdning.
